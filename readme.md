# 🔨 StructForge

**StructForge** is a lightweight graphical application that helps you create complex folder and file structures with ease.  
You can build your tree interactively using a visual tree view, or paste an indented text outline – and generate all folders/files on your disk with one click.

**ساختارشکن** (StructForge) یک برنامه‌ی گرافیکی ساده است که به شما کمک می‌کند ساختار پوشه‌ها و فایل‌های پیچیده را به‌راحتی ایجاد کنید.  
می‌توانید درخت را به‌صورت دیداری بسازید یا یک متن تورفتگی‌دار را جای‌گذاری کنید – و با یک کلیک، همه‌ی پوشه‌ها و فایل‌ها را روی دیسک ایجاد کنید.

---

## ✨ Features / قابلیت‌ها

- **Two input methods** / **دو روش ورودی**  
  1. **Interactive Tree** – Add/delete folders and files with right‑click or toolbar buttons.  
  2. **Text Import** – Paste an indented outline (spaces or tabs). Lines ending with `/` become folders; others become files.  

- **Build instantly** – Set the base path and click **Build** to create everything on disk.  

- **Portable executable** – Download the `.exe` from [Releases](https://github.com/mahanneman/StructForge/releases) and run it without installing Python.  

- **Clean and intuitive interface** – Built with Python's tkinter.

## 🚀 How to Use / نحوه‌ی استفاده

### With the .exe (easiest) / با فایل اجرایی (ساده‌ترین روش)
1. Download the latest `StructForge.exe` from [Releases](https://github.com/mahanneman/StructForge/releases).  
2. Run it – no installation required.  
3. Use the tree view or import a text outline, set the base path, and click **Build**.
