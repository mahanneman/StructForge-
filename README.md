# StructForge-
A graphical tool to create folder and file structures easily using a tree view or indented text input. Built with Python and tkinter. No installation required if you download the .exe from Releases. 


 Build the .exe yourself / ساخت فایل اجرایی توسط خودتان
bash
pip install pyinstaller
pyinstaller --onefile --windowed --name="StructForge" structforge.py
The .exe will be in the dist/ folder.
